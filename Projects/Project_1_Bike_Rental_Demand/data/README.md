# Data

The dataset is not included in this repository.

To reproduce the notebooks locally, place the original bicycle-rental file here as:

```text
data/bike_day_v2.xlsx
```

Running `01_data_understanding_and_preparation.ipynb` creates:

```text
data/bike_output.csv
```

which is used by the modelling notebooks.

Only redistribute the original data if its licence/ownership explicitly permits it.
